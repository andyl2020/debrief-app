# Debrief v1.11.2 - Working public Share Sets viewer

This patch fixes public Share Sets links that stayed on **Opening private
share…** instead of showing the shared sets. The Cloudflare repair is already
live and fixes existing links; owners do not need to recreate them. The Android
version is bumped so the installed build remains easy to identify.

## What changed

- Corrected duplicate Content-Security-Policy response headers that caused
  Chrome to block the viewer's own JavaScript and stylesheet.
- Corrected the same case-sensitive merge issue for route-specific cache
  headers.
- Added exact header regression coverage and a production browser smoke test.
  It creates a temporary private share, opens it in Chrome at a 412 x 915
  OnePlus-sized Android viewport, verifies the rendered transcript, comments,
  and audio player with no browser errors, and revokes the fixture.
- Added that browser smoke test to every future Cloudflare production deploy.
- Added a cached empty favicon response so successful pages do not emit a
  misleading 404 console error.

## How to use the fix

Open the same Share Sets link again. It should show every selected set with its
own audio player, transcript, and included comments. Existing links remain valid
until their configured expiry or manual revocation. If Chrome kept the failed
page open during deployment, close that tab and reopen the link once.

No recipient account or APK is required. The page remains read-only and does not
show a Download button. Link holders can still screen-record or capture content,
so continue using Debrief redactions before publishing sensitive material.

## Compatibility, limitations, and gotchas

- Android 10 or newer is required. The universal APK contains ARM64 and x86-64
  native libraries and is checked for the true 16 KB page environment used by
  modern devices such as the OnePlus 13.
- This patch does not change the encrypted database, sidecars, cloud schema,
  pairing credential, public URL format, or signing identity. It upgrades over
  v1.11.1 without clearing local data.
- Public pages require a current browser with JavaScript enabled. A revoked or
  expired link intentionally shows Share unavailable. A PIN-protected link still
  requires its PIN.
- Shares are immutable snapshots. Later transcript, comment, set, or redaction
  edits require revoking and creating a replacement if the published content
  itself must change.
- The APK remains sideloaded from GitHub, so Play Protect may show the normal
  unknown-developer warning. Install only the APK attached to this repository's
  release.
- Cloudflare usage is measured against the configured 10 GB R2 Standard
  reference; it is not a hard app-side quota and billing follows Cloudflare's
  account rules.
