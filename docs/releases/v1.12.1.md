# Debrief v1.12.1 — Web onboarding polish

## What changed

- The first-run storage screen now correctly tells iPhone and desktop users that the web recorder is available instead of describing it as Android-only.
- The official Debrief Cloud Worker URL is prefilled during pairing, removing an error-prone manual setup step.
- The web and Android companion versions are aligned at 1.12.1.

## Important iPhone limitation

Apple may suspend a PWA when the screen locks or another app takes the microphone. Keep Debrief visible while making an important long recording. Imported audio, transcription, review, comments, manual sets, redaction, sharing, cloud sync, and offline access remain available.

## Verification

- Web typecheck, full automated tests, production build, and dependency audit.
- Android unit tests and debug APK assembly.
- Production PWA, manifest, service worker, Cloud Worker health, and CORS checks.
