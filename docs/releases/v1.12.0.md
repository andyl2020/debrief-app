# Debrief v1.12.0 — Cross-platform release

## What is new

- Installable web/PWA app for iPhone, iPad, macOS, Windows, Linux, and modern Android browsers.
- Local/browser-folder audio library with AssemblyAI and Deepgram transcription.
- Offline browser recorder with editable filename, pause/resume, discard, frequent capture checkpoints, wake-lock request, and automatic external/default microphone routing where the browser exposes devices.
- Full review workflow: synced playback, transcript-only search, follow, 1–4x speed, 1/3/5-second skip, comments, speaker names, quality report, Markdown and Android sidecar export.
- Redaction mode defaults on. It masks text, mutes buffered audio ranges, supports whole-card redaction and per-word reveal, and excludes private redaction details from chapters.
- Manual set CRUD and colored scrubber ranges; automatic set detection remains removed.
- Share Sets on the web: select multiple completed sets, include their audio/transcript/comments in one 30/60/90-day private link, optional PIN, permanently apply current redactions, and manage expiry/revocation.
- Optional encrypted personal cloud library for cross-device access and seekable playback.
- Provider usage measured locally per browser.
- Visible `Debrief Web v1.12.0` label.

## Security and reliability

- Replaced the proposed unauthenticated AES-CTR cloud format with independently authenticated AES-GCM chunks while preserving byte-range seeking.
- Tampered, truncated, reordered, wrong-key, and cross-recording data fails closed.
- Current production Worker configuration is preserved; placeholder infrastructure identifiers are not shipped.
- Upgraded the web toolchain and removed all known npm audit findings at release time.
- Added web and Cloudflare CI gates alongside the existing Android workflows.

## How to use

1. Open the HTTPS web URL and choose browser storage (iPhone/iPad) or link a folder (desktop Chromium).
2. In Settings, create/unlock the key vault and add an AssemblyAI key (recommended) or Deepgram key.
3. Import audio or use Record. Select a recording and transcribe it.
4. Review it, add comments and manual set boundaries, and redact any private cards before sharing.
5. Pair the web app with the Debrief Cloudflare Worker to sync or publish Share Sets.
6. On iPhone/iPad, use Share → Add to Home Screen for an app-like launch.

## Limitations and gotchas

- Apple can suspend a PWA when its screen locks or another app takes the microphone. Keep Debrief visible for important long recordings; only Android's foreground service can guarantee screen-off capture.
- Safari browser storage is sandboxed and may be reclaimed. Cloud-sync or export sidecars for work that cannot be lost.
- Share preparation decodes audio locally and may use substantial memory for multi-hour sources.
- 3x/4x playback may be clamped by Safari.
- API key storage is passphrase-encrypted but cannot match Android's hardware-backed Keystore.
- AI Enhance remains Advanced/Experimental and Organize Recording remains optional on Android; AssemblyAI with Original upload is the recommended quality path.
