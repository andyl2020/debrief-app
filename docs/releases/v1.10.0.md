# Debrief v1.10.0 — Automatic microphone routing and durable markers

This reliability release automatically follows connected recording inputs and
adds redundant recovery copies for chapters, bookmarks/comments, redactions,
and speaker names.

## What changed

- The Recorder now shows **Phone microphone** or **External · device name**.
- Connected USB, wired-headset, Bluetooth/BLE, line, dock, and bus microphone
  inputs are detected automatically. USB is preferred when several external
  inputs are present; unplugging the external input returns to the built-in mic.
- Routing changes are applied to the active `MediaRecorder` in place. Debrief
  does not pause, stop, release, or recreate capture and does not restart the
  Media3 player.
- If Android refuses or does not honor a preferred input, recording continues
  on the system-selected input and the Recorder explains the problem.
- Manual sets/chapters, comments/bookmarks, redactions, and speaker names remain
  recording-bound SQLCipher rows across app updates, rescans, and retranscription.
- Every marker change also creates an encrypted app-private snapshot using
  verified atomic replacement and a previous-copy fallback.
- Debrief now keeps two verified JSON sidecar copies beside each audio file. If
  one is truncated or unreadable, the other can restore the transcript and
  markers after reinstall/rescan.
- Retranscription verifies the encrypted local marker snapshot before replacing
  transcript text. If local protection fails, nothing is replaced. A folder-only
  backup failure no longer falsely labels a completed transcription as failed.
- Review shows a compact **Retry backup** warning only while protected marker
  copies are out of date.

## How to use

### Microphone routing

1. Open **Record**. The chip below the level meter shows the selected input.
2. Connect an external microphone before or during recording. Debrief requests
   it automatically and the chip changes to **External** when Android routes it.
3. Unplug it to return to **Phone microphone**. Keep recording normally; there
   is no manual route switch.

### Marker protection

Use comments, manual sets, redactions, and speaker renaming normally. Backups are
automatic. If Review shows **Retry backup**, tap it. If the warning remains,
re-link the recordings folder and retry. Your database and encrypted local copy
remain usable while only the folder copy is unavailable.

## Limitations and edge cases

- Android owns the physical route transition. Debrief keeps its recorder/player
  alive, but a microphone or OEM audio stack can still introduce a brief click,
  silence, or gap while hardware changes.
- `setPreferredDevice` is a preference, not an absolute platform guarantee.
  Bluetooth profiles and some adapters may be rejected; Debrief warns and keeps
  recording from Android's selected input.
- Do not force-stop, reboot, uninstall, revoke microphone permission, fill/fail
  storage, or disconnect failing hardware during critical capture. No Android
  app can preserve audio that the OS/hardware never delivers.
- The encrypted app-private snapshot survives normal upgrades/retranscription,
  but uninstall or Clear data removes it. Paired sidecars beside the audio are
  the reinstall-safe copy.
- Sidecars are ordinary JSON and are not independently encrypted. Protect the
  linked folder/device because sidecars include transcript and marker text.
- Marker timestamps remain attached to the same audio timeline after
  retranscription. Replacing the underlying audio file with different content
  can make those timestamps semantically wrong.
- Android 10 or newer is required. The universal APK includes ARM64 and is
  verified for 16 KB memory pages used by the OnePlus 13.
- GitHub APKs are sideloaded, so Play Protect may show an unknown-developer
  warning. Install only the APK attached to this repository's release.

## Install and compatibility

Download `Debrief-v1.10.0.apk` and open it on the phone. It is production-signed
to upgrade v1.9.3 in place without removing recordings, transcripts, settings,
comments, sets, redactions, or speaker names.
